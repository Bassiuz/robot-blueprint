This site is the map of how I build software with AI agents. It has two halves.

**[Blueprints](/blueprints)**: subject-neutral starting points for a static
website, a Flutter app, a Flutter web app and cloud functions, plus how I
handle Firebase data, local databases and repository splits. One example
product, **Tally**, shows all of them working together.

**[How I work with agents](/agentic)**: the loop from idea to merged code, the
toolkit (Harbas, Agent Petting Zoo, Review Coach, Project Composer, Experiment Lab,
Seedling, Orca, lifebase), the agents and skills in use, what I retired and why,
the rules every agent gets, and an index of every memory and CLAUDE.md file.

(`blueprints/`, `agentic/`), so GitHub and this site always show the same text.
</Info>
